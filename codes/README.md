# Build Instructions

## Source Code

Write the source code in:

```text
Demo.c
```

## Build

Run the following command from the project root:

```bash
./build.sh *.c
```

## Output

After a successful build, the generated HEX file will be available at:

```text
out/Demo.hex
```

### Project Structure

```text
.
├── Demo.c
├── build.sh
└── out/
    └── Demo.hex
```
